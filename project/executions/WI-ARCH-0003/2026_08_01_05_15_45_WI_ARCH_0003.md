# Summary

Implements WI-ARCH-0003: replaces `RendererError`'s bare `String` payload
with a 7-variant enum, each `Display` arm owning its full message text —
structural error-model prep, not a behavior or output change.

# Result

Replaced `struct RendererError(String)` with an enum: `UnsupportedSurfaceFormat`,
`UnsupportedAlphaMode`, `MissingPresentMode`, `InsufficientLimits` (unit
variants for `Renderer::new`'s capability checks), `DeviceRequestFailed(String)`
(wraps the call site's `format!("{:?}", e)` output), `SurfaceTextureUnavailable`
(unit), and `FrameAcquisitionFailed(wgpu::CurrentSurfaceTexture)` (carries
the raw status value from `Renderer::render`).

Discovered and documented one forced exception to the work item's "no
pre-formatted call sites" rule, verified against the actual `wgpu` 29.0.3
source (`~/.cargo/registry/.../wgpu-29.0.3/src/api/device.rs`):
`wgpu::RequestDeviceError`'s only field is `pub(crate)` with no public
constructor, so it cannot be stored and later re-Debug-formatted from
outside `wgpu`, nor constructed directly in a unit test — unlike
`wgpu::CurrentSurfaceTexture`, which has publicly constructible unit
variants (`Lost`, `Outdated`, `Validation`) and was used directly in
`FrameAcquisitionFailed`. `DeviceRequestFailed` therefore stores the
already-Debug-formatted `String` the call site produces, accepting the
same call-site-formatting-drift risk the other variants deliberately
avoid, because no alternative is available. Documented this in a
type-level doc comment on `RendererError` and in the variant's own doc
comment.

Updated `From<RendererError> for JsValue` to `JsValue::from_str(&error.to_string())`
(the prior `error.0` direct tuple-field access no longer compiles on an
enum). Updated all 7 `RendererError::new(...)` construction call sites to
build the appropriate variant. Removed the now-unused `impl RendererError { fn new(...) }`
block.

Added `renderer_error_display_text_matches_exactly`, asserting all 7
variants' `Display` output against the exact original literal text,
including `FrameAcquisitionFailed(wgpu::CurrentSurfaceTexture::Lost)` and
a representative `DeviceRequestFailed` payload.
